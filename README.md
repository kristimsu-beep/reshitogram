# Решитограм (Reshitogram)

Adaptive WhatsApp-inspired messenger MVP built with FastAPI, MongoDB, WebSocket, Groq, Cloudflare Workers AI and OpenWeather.

## Deploy
1. In Render choose **New + → Blueprint**, then select this repository. Render will read `render.yaml`.
2. Create a MongoDB Atlas database and set `MONGODB_URI` in Render.
3. Add `GROQ_API_KEY`, `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`, and `OPENWEATHER_API_KEY` in Render Environment.
4. `JWT_SECRET` is generated by Render from the Blueprint.
5. Once deployed, visit `/health`; expected database status is `connected`.

Never commit API keys or database credentials. Use a strong MongoDB database password and secure Atlas network access.

## Included
Registration/login, persistent user accounts, user search, contacts, direct text chat via WebSocket, Groq AI chat/history, Cloudflare image generation, OpenWeather by city or coordinates, responsive interface.

## Not yet implemented
Group chats and admin permissions, 10-minute moderation mutes, push notifications, calls/video, and full notification UX. WebRTC calling needs STUN/TURN and usually an SFU for group calls. Push notifications require a service worker, VAPID keys and device subscriptions. WebSocket presence currently runs in one process and needs shared pub/sub for multi-instance scaling.

This is an initial MVP scaffold, not a security-reviewed production messenger. Add rate limiting, email verification, abuse reporting, backup/retention policies and a proper production security review before public launch.
